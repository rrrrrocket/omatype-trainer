**Maintainer notes:**

Omatype-trainer is an offline typing-practice bar widget maintained by rocket. It saves practice history locally to `~/.local/state/omarchy/typing-trainer.json` and plays sound using PipeWire's `pw-play`. It requires no network, elevated privileges, or background service. The repository includes install and removal instructions, the complete AGPL-3.0-only license, attribution for keybr's AGPL-3.0 data and adapted generator, and a `preview.png` for the listing. The plugin does not overwrite user configuration. I own the Omatype code and preview images and have included keybr's license and attribution.
